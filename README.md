# Curly Lab — Sitio web de presentación

Sitio estático y responsive para presentar el negocio **Curly Lab** y la aplicación móvil **Rizo ID**.

## Abrir localmente

Haz doble clic en `index.html` o ábrelo con la extensión **Live Server** de Visual Studio Code.

## Publicar gratis con GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `curly-lab-web`.
2. Sube todos los archivos y la carpeta `assets` a la raíz del repositorio.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub mostrará la dirección pública después de unos minutos.

La URL normalmente tendrá este formato:

`https://TU-USUARIO.github.io/curly-lab-web/`

## Funciones incluidas

- Diseño responsive para computadora y celular.
- Menú de navegación adaptable.
- Demostración interactiva de las pantallas de Rizo ID.
- Galería ampliable de los espacios del salón.
- Sección de membresía Curly Lab Plus.
- Formulario funcional para demostración sin backend.
- Animaciones suaves al desplazarse.
